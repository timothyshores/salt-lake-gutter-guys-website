# Salt Lake Gutter Guys

Single-page website for a Salt Lake City gutter contractor.

**Live: https://timothyshores.github.io/salt-lake-gutter-guys-website/**

Static HTML and CSS. No build step, no framework, no dependencies. Everything
is in `index.html`.

Deployed by GitHub Pages from the `master` branch, root folder. Push to
`master` and the live site updates in about a minute.

The contact form posts to Formspree.
